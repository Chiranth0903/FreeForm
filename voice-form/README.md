# FreeForm AI

See the [project README](../README.md) for features, installation, usage, privacy, troubleshooting, and tests.

From this folder, load `extension` in Chrome using Load unpacked, run the demo with `node serve.cjs`, or run tests with `node --test test.cjs voice-session.test.cjs`.

For sharing, use `FreeForm-AI-Ready-to-Install.zip`. Extract it fully and select its extracted folder containing manifest.json directly inside.
